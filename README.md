### 2단계: 교육용으로 단순화 요청

**사용자 요청:**
> 이 시뮬레이터로 프로그래밍 초보자에게 조건문을 가르치려고 해.
> 함수를 사용하지 말고 맑음, 흐림, 비 3가지의 경우에 각각 다른 음식을 선택하는 시뮬레이터로 변경해줘.
> 파이썬 코드를 학생들이 직접 변경하면서 조건문을 이해하는 것을 도와주는 것이 주 목적이야.

**변경 내용:**

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 날씨 종류 | 6가지 | 맑음·흐림·비 3가지 |
| 코드 구조 | `def recommend_menu()` 함수 사용 | 함수 없이 `if/elif/else`만 사용 |
| 변수 | 복잡한 로직 | `weather`, `menu`, `reason` 3개 |
| 온도 | 슬라이더 있음 | 제거 |
| 출력 | 없음 | `print()` 출력 시뮬레이션 추가 |
| UI | 실행 로그 패널 | 조건문 개념 설명 패널로 교체 |
| 추가 | 없음 | 하단 도전 과제 배너 |

**최종 파이썬 코드 구조:**
```python
weather = "맑음"

if weather == "맑음":
    menu = "샌드위치 🥪"
    reason = "맑은 날엔 밖에서 샌드위치를 먹어요!"

elif weather == "흐림":
    menu = "라면 🍜"
    reason = "흐린 날엔 따뜻한 라면이 딱 좋아요!"

elif weather == "비":
    menu = "파전 🥞"
    reason = "비 오는 날엔 파전이 최고죠!"

else:
    menu = "편의점 도시락 🍱"
    reason = "모르는 날씨엔 편의점 도시락!"

print("오늘 날씨:", weather)
print("추천 메뉴:", menu)
print("이유:", reason)
```

### 4단계: 간단한 프롬프트 요청

**사용자 요청:**
> 지금 만든 index.html을 만들려면 좀 간단한 프롬프트를 만들어줘.
> 파이썬 코드를 변경해서 if문을 학습할 수 있도록 파이썬 코드를 오른쪽에 볼 수 있도록 해줘 라는 의도가 들어가 있는 프롬프트를 좀 간단히 만들어줘.

**AI가 작성한 3가지 버전:**

#### 짧은 버전 (한 문단)
```
파이썬 if/elif/else 조건문을 학습하는 웹 실습 도구를 HTML, CSS, JS로 만들어줘.
왼쪽에는 코드 편집기(CodeMirror)가 있고 학생이 파이썬 코드를 직접 수정할 수 있어야 해.
오른쪽에는 3가지 선택 버튼(예: 맑음, 흐림, 비)과 실행 결과가 표시돼.
버튼을 누르면 코드의 변수가 바뀌고, 실행 버튼을 누르면 어떤 if가 참인지
✅/❌로 보여줘. 함수는 사용하지 않고 if/elif/else만 쓰는 초보자용이야.
다크 모드 디자인으로 만들어줘.
```

#### 학생 배포용 (주제만 교체)
```
파이썬 if/elif/else 조건문을 배우는 웹 실습 도구를 만들어줘.

주제: [날씨(맑음, 흐림, 비)에 따라 음식 메뉴를 선택하는 프로그램]

조건:
- 왼쪽에 파이썬 코드 편집기(CodeMirror)를 넣고 학생이 직접 수정 가능
- 오른쪽에 선택 버튼 3개, 실행 결과, if/elif/else 개념 설명
- 버튼 누르면 코드 변수가 바뀌고, 실행하면 조건 흐름을 ✅/❌로 표시
- 함수 사용하지 않기, 다크 모드, 이모지 포함
- 파일: index.html, style.css, app.js
```

## 🎯 핵심 교육 목표

1. `if` → 첫 번째 조건을 검사한다
2. `elif` → 앞 조건이 거짓일 때 다음 조건을 검사한다
3. `else` → 모든 조건이 거짓일 때 실행한다
4. `==` → 두 값이 같은지 비교한다
5. 들여쓰기(indent) → 조건에 속하는 코드를 구분한다
