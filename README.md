### 1단계: 최초 요청 — 날씨 음식 메뉴 시뮬레이터

**사용자 요청:**

> 사용된 파이썬 코드를 화면에 볼 수 있게 해주고 수정도 가능하게 해줘.

**AI가 만든 결과:**

- `def recommend_menu()` 함수 사용
- 온도 슬라이더 포함
- CodeMirror 기반 코드 편집기
- 실행 로그 패널

**생성 파일:** `index.html`, `style.css`, `app.js`

### 2단계: 교육용으로 단순화 요청

**사용자 요청:**
> 이 시뮬레이터로 프로그래밍 초보자에게 조건문을 가르치려고 해.
> 함수를 사용하지 말고 맑음, 흐림, 비 3가지의 경우에 각각 다른 음식을 선택하는 시뮬레이터로 변경해줘.
> 파이썬 코드를 학생들이 직접 변경하면서 조건문을 이해하는 것을 도와주는 것이 주 목적이야.

**변경 내용:**

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 날씨 종류 | 6가지 | 맑음·흐림·비 3가지 |
| 코드 구조 | `def recommend_menu()` 함수 사용 | 함수 없이 `if/elif/else`만 사용 |
| 변수 | 복잡한 로직 | `weather`, `menu`, `reason` 3개 |
| 온도 | 슬라이더 있음 | 제거 |
| 출력 | 없음 | `print()` 출력 시뮬레이션 추가 |
| UI | 실행 로그 패널 | 조건문 개념 설명 패널로 교체 |
| 추가 | 없음 | 하단 도전 과제 배너 |

**최종 파이썬 코드 구조:**
```python
weather = "맑음"

if weather == "맑음":
    menu = "샌드위치 🥪"
    reason = "맑은 날엔 밖에서 샌드위치를 먹어요!"

elif weather == "흐림":
    menu = "라면 🍜"
    reason = "흐린 날엔 따뜻한 라면이 딱 좋아요!"

elif weather == "비":
    menu = "파전 🥞"
    reason = "비 오는 날엔 파전이 최고죠!"

else:
    menu = "편의점 도시락 🍱"
    reason = "모르는 날씨엔 편의점 도시락!"

print("오늘 날씨:", weather)
print("추천 메뉴:", menu)
print("이유:", reason)
```
